# 3. Сценарії якісних атрибутів (Quality Attribute Scenarios)

### QAS-1: Продуктивність під час масового розпродажу (Performance Efficiency — Time Behaviour & Capacity)
- **Source:** Зареєстровані клієнти маркетплейсу через Web та Mobile клієнти.
- **Stimulus:** Різке зростання кількості запитів на додавання до кошика та створення замовлення під час старту акції «Black Friday».
- **Environment:** Режим пікового навантаження (Peak Load, 3 000 RPS).
- **Artifact:** API Gateway та Сервіс Замовлень (Order Processing Module).
- **Response:** Запити приймаються шлюзом, перевіряються на валідність, публікуються в чергу брокера повідомлень (Message Broker) для асинхронної обробки, клієнту повертається відповідь `202 Accepted` з унікальним номером відстеження.
- **Response Measure:** Затримка клієнтської відповіді $p99 < 180\text{ ms}$; 0% втрачених замовлень; утилізація CPU нод не перевищує 80%.

---

### QAS-2: Відмовостійкість ядра бази даних (Reliability — Fault Tolerance & Recoverability)
- **Source:** Апаратна відмова фізичного сервера або дискового накопичувача основної ноди СУБД.
- **Stimulus:** Раптове переривання роботи процесу Primary PostgreSQL інстансу під час активного потоку операцій запису.
- **Environment:** Нормальний робочий режим системи.
- **Artifact:** Кластер PostgreSQL та механізм Failover (Patroni / PgBouncer).
- **Response:** Монітор кластера фіксує втрату лідера, ініціює вибори нового лідера серед синхронних реплік, оновлює маршрути пулера з'єднань і перемикає клієнтський трафік на нову Primary-ноду.
- **Response Measure:** Час перемикання (RTO) $\le 25\text{ с}$; втрата зафіксованих комітів $RPO = 0$; фонові повторні спроби сервісів завершуються без випадання 500 Internal Server Error клієнту.

---

### QAS-3: Запобігання підбору паролів та захист API (Security — Authenticity & User Error Protection)
- **Source:** Розподілений ботнет або зловмисник.
- **Stimulus:** Спроба атаки методом брутфорсу з надсиланням 500 запитів автентифікації на хвилину на ендпоінт `/api/v1/auth/login`.
- **Environment:** Звичайне робоче середовище.
- **Artifact:** API Gateway / WAF та Auth Service.
- **Response:** Спрацьовує лімітер запитів (Rate Limiting на основі алгоритму Token Bucket у Redis), шлюз тимчасово блокує IP-джерела на 30 хвилин і віддає статус `429 Too Many Requests`, записуючи подію в журнал аудиту безпеки.
- **Response Measure:** Атака локалізується протягом $\le 1$ секунди; легітимні користувачі не відчувають деградації швидкості відповіді (overhead latency < 5 ms); компрометація акаунтів 0%.

---

### QAS-4: Модифікованість системи під нові платіжні провайдери (Maintainability — Modifiability)
- **Source:** Розробник бекенд-системи маркетплейсу.
- **Stimulus:** Потреба додати новий платіжний метод (наприклад, криптопроцесинг або локальний банківський еквайринг).
- **Environment:** Плановий спрінт розробки та виконання регресійного CI/CD пайплайну.
- **Artifact:** Платіжний модуль (Payment Gateway Integration Module).
- **Response:** Завдяки реалізації паттерну Strategy/Adapter новий платіжний провайдер підключається через реалізацію інтерфейсу `IPaymentProcessor` без зміни кодової бази ядра оформлення замовлень.
- **Response Measure:** Розробка, тестування та інтеграція адаптера займає $\le 16$ інженерних годин; нуль дефектів у наявних платіжних процесорах.

---

### QAS-5: Еластичність споживання ресурсів при зниженні активності (Flexibility — Scalability)
- **Source:** Автоматична телеметрія системи моніторингу (Prometheus / Kubernetes Metrics Server).
- **Stimulus:** Зниження інтенсивності трафіку покупців з 3 000 RPS до 150 RPS у нічний час (після 02:00).
- **Environment:** Перехідний стан після пікового навантаження.
- **Artifact:** Контейнерний оркестратор та пул бекенд-інстансів (App Pods).
- **Response:** Механізм HPA плавно масштабує пул контейнерів до мінімально заданого рівня з виконанням процедури коректного завершення (Graceful Shutdown) для активних з'єднань.
- **Response Measure:** Зменшення кількості виділених реплік до базового мінімуму за час $\le 4$ хвилин; жоден активний сеанс або запит не обірвано помилкою (0% drop rate).
